## 三、作業問題回答

### 問題一：為什麼 `"4"` 要先轉成數字，才能用於本題的分攤計算？
在 Python 中，加上引號的 `"4"` 是**字串（`str`）**型別，電腦會把它當作一般的文字符號，而不是可以做加減乘除的數值。如果直接拿應付總額（數字型別 `float`）去除以字串 `"4"`，Python 會因為型別不相容而產生 `TypeError` 錯誤，無法執行除法運算。因此必須先透過 `int("4")` 將其轉換為整數（`int`），才能正確計算每人分攤的金額。

### 問題二：如果先扣折價券，再依剩餘餐費計算服務費，第一組的應付總額會變成多少？為什麼和題目規定的結果不同？
* **先扣折價券再算服務費的算式**：
  1. 扣除折價券後的餐費：$1,200 - 100 = 1,100$ 元
  2. 依剩餘餐費計算 10% 服務費：$1,100 \times 0.10 = 110$ 元
  3. 應付總額：$1,100 + 110 = 1,210$ 元（會變成 **1,210 元**，比題目規定的 1,220 元少了 10 元）。
* **結果不同的原因**：
  因為計算服務費的「基準金額（母數）」不同。題目規定服務費必須以「原始餐費 1,200 元」計算（服務費 120 元），之後才扣折價券；若先扣除 100 元折價券，計算服務費的基準就會縮水成 1,100 元，導致折價券的 100 元也被少算了 10% 的服務費（$100 \times 0.10 = 10$ 元），造成最終總額差了 10 元。
